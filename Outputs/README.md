# This Folder Contains All Supporting Data Used in the Research Paper Titled:  
## Sentiment Analysis of Online Product Reviews using Explainable AI Supported Heterogeneous Stacking Ensemble Approach to Identify the Effects of Polarity Shift Handling

1. **"Base_Learner_Outputs"** contains the outputs of all base learners and their configurations:
- Classification Reports
- The Rule Summaries
- Audit Summary
- Affected Reviews
- Sentiments
- Probability Estimates/Scores

2. **"Meta_Learner_Outputs"** contains the outputs of all meta learners and their configurations:
- Classification Reports
- XAI Explanations
- XAI Global Charts
- XAI Sample Review Charts (Local explanations)

3. **"Confusion_Matrices.zip"** contains the confusion matrices for every model and their corresponding configurations:
- Baseline Base Learners
- Enhanced Base Learners
- Baseline Meta Learners
- Baseline-Extra Meta Learners
- Mixed Meta Learners
- Enhanced Meta Learners

4. **"Exact_McNemar_Bonferroni_Results.zip"** contains the statistical results related to the exact McNemar tests conducted:
- Comparisons of each Baseline-Extra Meta Learner Vs Baseline Meta Learner
- Comparisons of each Mixed Meta Learner Vs Baseline Meta Learner
- Comparisons of each Enhanced Meta Learner Vs Baseline Meta Learner
- Comparison of each Enhanced Base Learner Vs Baseline Base Learner
- Comparison of each Baseline Meta Learner Vs Baseline RoBERTa
- Comparison of each Enhanced Meta Learner Vs Enhanced RoBERTa
