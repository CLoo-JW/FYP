# This Repository Contains the Code and Supporting Results for the Following Research Paper:  
## Sentiment Analysis of Online Product Reviews using Explainable AI Supported Heterogeneous Stacking Ensemble Approach to Identify the Effects of Polarity Shift Handling

The source datasets were not included in this repository due to file size limits. Place the CSV files inside Dataset/Reviews/ before running the project. The datasets used can be found through these links:  
1. https://www.kaggle.com/datasets/fawadhossaini1415/amazon-fashion-800k-user-reviews-dataset
2. https://www.kaggle.com/datasets/mohamedbakhet/amazon-books-reviews?select=Books_rating.csv
3. https://www.kaggle.com/datasets/magdawjcicka/amazon-reviews-2018-electronics?select=electronics_small.csv

lid.176.bin was also excluded due to file size limits. Place this file inside Datasets/ before running the project. The file can be found from the following link:  
- https://www.kaggle.com/datasets/fbt97119/lid176bin

To install dependencies: pip install -r requirements.txt

**The model outputs and supporting results and data can be found in the Outputs File**
